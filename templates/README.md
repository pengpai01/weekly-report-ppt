# 官方周总结模板

导出直接打开并填写：

```
templates/week-summary-template.pptx
```

该文件已在仓库中。文档和代码只使用这条相对路径，不要写本机盘符路径。

预览和导出都走 `fillOfficialTemplate()`（`src/lib/exportPptx.ts`）。它在浏览器里用 JSZip 读取该 pptx（pptxgenjs 不能打开已有文件），只替换模板里的文字。预览把填好的形状画出来，不另画一套版式：

- 封面：保留模板封面图元和标题/部门/日期的位置。有汇报人时在同一信息块加一行
- 项目进展：复制模板第二页，标题用模板标题样式，要点写入版式左右正文占位（含层级）
- 目录、章节、问题与下周计划套用同一正文页，避免另画版式
- 模板第三页是「感谢您的聆听」加 1ppt.com 广告文本。导出删掉广告形状，结束语改成「感谢聆听」，不保留广告页
